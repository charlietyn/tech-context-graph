# Tech Context Graph Roadmap

## 4.0 - Explicit workspace and roots

- Workspace registry and marker.
- No silent path assumptions.
- Multiple repository roots.
- Candidate review states.
- Searchable repository selection.
- SQLite control plane.
- Bilingual manuals and diagrams.

## 4.1 - Reliability and validation

- `tcg config:validate`.
- SQLite backup and migration doctor.
- Crash recovery for interrupted inspections.
- Disk-space and permission preflight.
- Root relocation and repository reconciliation.

## 4.2 - Inspection intelligence

- Graph build manifests and lock files.
- Per-repository Graphify profiles.
- Graph diff and inspection history.
- Better Git dirty-state summaries.
- Batch selection filters.

## 4.3 - Knowledge workflows

- Business/document discovery workflow in the same workspace manager.
- Canonical documentation approval dashboard in CLI.
- Traceability coverage reports.
- Query router across business, code, database and unified graphs.

## 5.0 - NestJS server foundation

- NestJS application libraries.
- API and workers.
- PostgreSQL and object storage.
- Authentication and RBAC.
- Remote/local runner protocol.

## 6.0 - Visual control plane

- Web workspace dashboard.
- Repository and root manager.
- Job history and live logs.
- Graph explorer.
- Questions, approvals and traceability views.
