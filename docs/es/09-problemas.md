# Solución de problemas

**No existe workspace:** ejecuta `tcg` o usa `--workspace`.

**La carpeta no es workspace:** utiliza la opción de abrir/adoptar para crear el marcador con confirmación.

**No se detectan repositorios:** revisa la raíz, profundidad y catálogo tecnológico.

**Graphify no existe:** instala con `uv tool install graphifyy` y verifica `graphify --version`.

**Grafo STALE:** el código cambió; utiliza **Update graph**.
