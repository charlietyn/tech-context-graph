## Una nota para principiantes

No necesitas saber teoría de grafos para utilizar este proyecto. Un nodo es simplemente una entidad, como un archivo, clase, función, módulo o concepto. Una arista representa una relación significativa, como «importa», «llama», «contiene» o «depende de». Aprende primero el flujo de trabajo y añade el vocabulario técnico cuando te resulte útil.
