# Glosario

**Workspace:** carpeta de control con estado, configuración y grafos.

**Raíz:** árbol elegido explícitamente para buscar repositorios.

**Candidato:** carpeta detectada pendiente de aceptación.

**Repositorio aceptado:** repositorio autorizado para Graphify.

**Fingerprint:** resumen utilizado para detectar cambios.

**Plano de control:** configuración, estado, trabajos y decisiones.

**Plano de datos:** repositorios, procesos y artefactos.
