# Glossary

**Workspace:** control folder containing state, configuration and graph artifacts.

**Repository root:** explicitly chosen folder tree searched for repositories.

**Candidate:** detected folder awaiting human acceptance.

**Accepted repository:** repository permitted to be inspected by Graphify.

**Fingerprint:** compact representation used to detect source changes.

**Graph artifact:** Graphify `graph.json` and related output.

**Control plane:** configuration, state, jobs and decisions.

**Data plane:** files, repositories, Graphify processes and graph artifacts.
