## A note for beginners

You do not need graph theory to use this project. A node is simply a thing—such as a file, class, function, module, or concept. An edge is a meaningful relationship between two things—such as “imports,” “calls,” “contains,” or “depends on.” Start with the workflow, then learn the vocabulary when it becomes useful.
