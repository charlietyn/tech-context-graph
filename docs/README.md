# Documentation

Tech Context Graph documentation is maintained in English and Spanish. Both collections follow the same learning sequence so readers can move between languages without losing the conceptual structure.

## Choose a language

- [English documentation](en/README.md)
- [Documentación en español](es/README.md)

## Recommended learning sequence

1. Understand the problem and mental model.
2. Create a workspace.
3. register repository search roots.
4. detect and review candidates.
5. inspect accepted repositories with Graphify.
6. query graphs and understand freshness.
7. connect a graph to an AI workflow only after reviewing security boundaries.

The root [README](../README.md) is the public project introduction. These chapters are the operational and conceptual reference.
